# Drivers of the Asymmetric ITCZ Bias in Climate Models

This repository contains the **analysis and plotting code** used in:

**Choi, N., Quan, X.-W., & Stan, C. (2026). *Drivers of the Asymmetric ITCZ Bias in Climate Models*. Scientific Reports.**

**DOI:** https://doi.org/10.1038/s41598-026-67513-x

## Overview

This study investigates the physical drivers of asymmetric precipitation biases associated with the Intertropical Convergence Zone (ITCZ) in high-resolution coupled climate models.

The analysis combines high-resolution climate model simulations, observational and reanalysis datasets, and single-column model experiments to examine the relative roles of sea surface temperature and atmospheric thermodynamic structure in controlling ITCZ precipitation biases.

The notebooks in this repository contain the analysis and plotting procedures used to produce the main and supplementary figures presented in the paper.

## Data

The following observational and climate-model datasets used in this study are publicly available:

* **GPCP v3.3 precipitation**
  https://doi.org/10.5067/MEASURES/GPCP/DATA306

* **NOAA OISST v2 sea surface temperature**
  https://www.ncei.noaa.gov/products/optimum-interpolation-sst

* **ERA5 atmospheric reanalysis**
  https://doi.org/10.24381/cds.6860a573

* **CMIP6 HighResMIP simulations**
  https://pcmdi.llnl.gov/CMIP6/

The specific HighResMIP models and experimental configurations used in the analysis are described in the paper.

The UFS Prototype 8 climate simulation outputs and CCPP Single-Column Model (SCM) experiment outputs used in this study are available from the corresponding author upon reasonable request.

## Reproducibility Notes

The notebooks were developed using the computational environment employed for the original analysis. Some notebooks therefore contain local paths corresponding to the original data storage system.

To reproduce the analysis on another system, users should modify the input and output paths according to their local data locations.

Some analyses also use intermediate files generated by preceding analysis steps. The observational and HighResMIP input datasets should be obtained from the sources listed above. UFS Prototype 8 and SCM experiment outputs can be requested from the corresponding author.
